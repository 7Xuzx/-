# 云筑 · 家｜107㎡全屋 3D 设计

广州云筑上品 107㎡四房的可交互概念方案。以业主提供的精装灰色石纹瓷砖、浅橡木色鱼骨纹砖和室内参考照片为材质依据。

## 使用

打开部署后的 `index.html`。本地预览需要 Node.js：

```sh
node server.cjs
```

访问 `http://127.0.0.1:4173`。生产文件均位于 `dist/`，可直接部署到 GitHub Pages 或其他静态托管。Three.js 已包含在 `dist/vendor/`，运行无需 npm 安装。可选在线字体无法加载时会自动使用本机中文字体。

## 功能

- 全屋 3D 旋转、缩放和平移；可切换正上方平面视图。
- 点击空间导航或模型标签，查看客餐厅、主卧、儿童房、次卧、多功能房、卫浴。
- 室内视角拖动环顾，W A S D / 方向键 / 触屏按钮移动；墙体限制基础移动范围。
- 卧室鱼骨拼与直铺对比；日夜氛围；完整墙体与低墙透视；标签开关。
- 全屋自动导览、全屏、保存当前 3D 效果图。
- 材质实拍与户型来源；响应式手机页面；WebGL 不可用时可查看参考资料。

## 设计依据与精度

107㎡为业主提供的建筑面积，不等于本模型的实测套内面积。

户型按[公开户型参考](https://www.sohu.com/a/1035574656_122525359)中的“云启 · 建筑面积约107㎡”四房两厅两卫组织，并结合[业主提供的看房视频](https://xhslink.cn/o/asOJ5JRrss)的字幕线索：入户多功能房、U 型厨房、约 5.2 米阳台、两间次卧、带独卫的主卧。图中文字与视频对阳台面宽的描述存在小幅差异，模型采用视频约 5.2 米的线索。

尚无业主合同户型图与现场测量数据。墙体位置、门窗、层高、家具与尺寸均为近似推演，模型不能作为施工图、拆改依据或材料算量依据。房屋朝向未确认，界面指南仅示意。主卧套房走道、卫浴和家具布置为概念方案，须实测校准。

3D 石纹与木纹为程序化示意材质，右侧可对照业主提供的真实照片；图片的拍摄光线会影响颜色。鱼骨纹铺法、规格、拼角、缝宽及色号需与商家确认。

## 文件

- `dist/index.html`、`style.css`：中文交互界面与移动端布局。
- `dist/app.js`：Three.js 模型、材质、相机与交互逻辑。
- `dist/assets/`：业主照片节选与公开户型参考图。
- `dist/vendor/`：Three.js 0.170.0 和 OrbitControls，MIT 许可。
- `server.cjs`：本地静态服务器。
